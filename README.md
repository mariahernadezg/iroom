#Proyecto Smart Room

Práctica de desarrollo web (CSS, HTML)

## Descripción
Página web que recoge y muestro los datos de una habitación inteligente a través de varios sensores.

## Contenido
- "index.html": página principal
- "config.html": página de configuración de los sensores y formulario
- "minombre.html": almacenamiento del nombre del usuario
- "iroom.css": hoja de estilos

## Tecnologías

- HTML
- CSS
- JavaScript

## Servidor

La aplicación se ha desplegado en un servidor Apache mediante un
host virtual.
